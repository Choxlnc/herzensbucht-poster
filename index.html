Herzensbucht Poster

Herzensbucht Poster ist ein privates Desktop-Werkzeug, mit dem die Betreiberin eigene Bilder und Videos auf ihre eigenen TikTok-Konten hochlädt. Das Werkzeug wird ausschließlich intern genutzt und steht nicht öffentlich zum Download bereit.

Funktionsweise

  • Das Programm läuft lokal auf einem Windows-Rechner.
  • Die Anmeldung erfolgt über TikTok Login Kit (OAuth) mit den eigenen Konten.
  • Beiträge werden über die TikTok Content Posting API veröffentlicht.
  • Es werden keine Inhalte Dritter verarbeitet und keine Daten an Dritte übermittelt.
